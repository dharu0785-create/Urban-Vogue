# Urban-Vogue

A modern, responsive e-commerce web application for **Urban Vogue**, built with React, Vite, and modern CSS.

---

### ✨ Features
- **Modern Dark Aesthetic:** Glassmorphism, subtle micro-animations, and responsive layout.
- **Header & Navigation:** Sticky blur header with cart badge counter and mobile navigation drawer.
- **Home Page (`/`):** Hero section with Call-To-Action, featured top 10 products, and 4 value proposition cards.
- **Shop Page (`/shop`):** 50 curated fashion items with dynamic filters (Category, Price Range Slider ₹1,500 – ₹3,000, and Sorting).
- **Cart Drawer:** Slide-out drawer with quantity controls, remove item, real-time free shipping progress bar, and itemized subtotal.
- **Checkout Page (`/checkout`):** Seamless checkout flow with address form, multiple Indian payment options (UPI, Card, Net Banking, COD), and order confirmation.
- **About Us Page (`/about`):** Brand story, mission, vision, and core values under the Dharu ram entity.
- **Contact Us Page (`/contact`):** Working contact form, operating address, business hours, and FAQ section.
- **Legal Pages (`/terms`, `/privacy`):** Terms & Conditions and Privacy Policy complying with GST and Indian e-commerce standards.

### 🚀 Getting Started

#### Prerequisites
- Node.js (v18+)
- npm or yarn

#### Installation
```bash
# Clone the repository
git clone https://github.com/dharu0785-create/Urban-Vogue.git

# Navigate to the project directory
cd Urban-Vogue

# Install dependencies
npm install

# Start local development server
npm run dev
```

#### Build for Production
```bash
npm run build
```
